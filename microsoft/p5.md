## 2. Automated Rolling Update Flowchart (`deploy.sh`)

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                        AUTOMATED ROLLING UPDATE DEPLOYMENT PIPELINE                              │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘

  Step 1: PRE-FLIGHT VALIDATION
  • Validates SSH key permissions (chmod 600)
  • Checks remote VM SSH connectivity: ssh ubuntu@129.154.39.198
              │
              ▼
  Step 2: CODEBASE DELTA SYNC
  • Runs `rsync -avz --delete` excluding node_modules, .git, and .env
              │
              ▼
  Step 3: REMOTE CONTAINER COMPILATION
  • Hydrates production secrets into k8s manifests using `sed`
  • Compiles container image directly on VM: `docker build -t magnus-api .`
  • Imports image into K3s runtime: `k3s ctr image import`
              │
              ▼
  Step 4: ROLLING RESTART WITH TIMEOUT
  • Applies manifests: `kubectl apply -f /tmp/magnus-k8s-hydrated/`
  • Initiates rolling restarts: `kubectl rollout restart deployment magnus-api magnus-worker`
  • Monitors rollout status with a 90-second timeout guard
              │
              ▼
  Step 5: PROXY & HEALTH VERIFICATION
  • Tests Nginx syntax: `nginx -t` && reloads Nginx systemd service
  • Executes HTTP health check against `/ci/` verifying HTTP 200 OK
  RESULT: Zero-downtime rolling update completed in under 45 seconds!
```

## 3. Frontend Terminal Virtualization: CSS vs. React Windowing

| Feature / Metric | CSS `content-visibility: auto` (MagnusCI) | JavaScript Virtualization (`react-window`) | Naive DOM Rendering (No Virtualization) |
| :--- | :--- | :--- | :--- |
| **JS Bundle Overhead**| **0 KB** (Native browser rendering engine) | ~30 KB library overhead | 0 KB |
| **Browser Search (Cmd+F)**| **100% Native Support** (All text in DOM tree) | **Broken** (Unmounts off-screen DOM nodes) | Works (until browser crashes) |
| **Rendering Performance**| **60 FPS** (Layout/paint skipped for off-screen) | 60 FPS (Constant ~50 DOM nodes) | Drops to < 10 FPS past 5,000 lines |
| **DOM Memory Overhead**| Low (Lightweight element representations) | Minimal (Only visible rows exist) | Severe (50,000+ full DOM nodes) |
| **Scrollbar Accuracy**| Minor jitter on rapid scroll (`contain-intrinsic-size`)| Pixel-perfect scrollbar calculations | Pixel-perfect scrollbar calculations |

```css
/* frontend/src/index.css */
.terminal-line {
  content-visibility: auto;
  contain-intrinsic-size: 0 24px;
}
```

## 4. Infrastructure & Deployment Failure Matrix

| Failure Mode | Root Cause | System Reaction | Recovery / Mitigation |
| :--- | :--- | :--- | :--- |
| **Pod Eviction Mid-Build** | Rolling update triggers `SIGTERM` on active worker pod | Kubernetes allows 30s grace period before `SIGKILL`. In-flight build interrupted. | BullMQ stalled-job detector catches expired 300s lock; re-queues build on new pod. |
| **Host Disk Exhaustion** | Old build workspaces and dangling Docker layers pile up | `cleanup.sh` cron job runs every 6 hours | Prunes dangling images (`docker image prune -f`) and wipes `/tmp/magnus-builds` > 24h old. |
| **Nginx Proxy Disconnect** | Long build stage runs without output for > 60s | Nginx configured with `proxy_read_timeout 3600s` + Socket.io 25s ping heartbeats | Socket remains open for up to 1 hour; NAT gateways kept warm by heartbeat pings. |
| **Corrupted Rollout Image** | Compilation failure during remote `docker build` | `deploy.sh` script halts immediately (`set -e`) before applying manifests | Kubernetes keeps existing healthy pods running; zero downtime on failed build. |

## 5. Rapid Interview Talking Points (60 Seconds)

- **Single-Node K3s Topology:** All services (API, Worker, Redis, Postgres, MinIO) run as isolated pods on an Oracle Cloud VM, fronted by Nginx reverse proxy with SSL termination.
- **Automated Rolling Updates:** `deploy.sh` handles secret hydration, in-VM image compilation, rolling restart monitoring, and HTTP health verification with automated rollback on failure.
- **Frontend Optimization:** Used CSS `content-visibility: auto` to skip off-screen rendering for 50,000+ log lines at 60 FPS while preserving native browser search (Cmd+F).
- **Senior Reflection:** Lack of a `preStop` drain hook in the worker deployment is our primary operational gap; productionizing requires adding a drain hook with `worker.pause(true)` and `terminationGracePeriodSeconds: 600`.
