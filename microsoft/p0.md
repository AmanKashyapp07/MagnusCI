## 4. Visual Flowcharts: Top 3 Real Bugs Diagnosed & Fixed

### Bug #1: Docker `AutoRemove` Log Truncation Race
```
 [ AI SUGGESTION: AutoRemove: true ]
  Container Exits (exit code 1) ──► Docker Daemon DESTROYS container instantly!
                                           │
                                           ▼ (RACE CONDITION)
                                Node.js stdout stream STILL DRAINING!
                                Socket closes abruptly ──► Log buffer truncated!
                                RESULT: User sees blank screen on failure!

 [ CANDIDATE FIX: EXPLICIT FINALLY-BLOCK TEARDOWN ]
  1. Set AutoRemove: false
  2. Await full stream flush & collect container.wait() exit code
  3. finally { await container.remove({ force: true }); }
  RESULT: 100% of terminal stderr captured before container removal!
```

### Bug #2: Circular DAG Dependency Infinite Execution Hang
```
 [ SCENARIO: Developer configures A depends on B, B depends on A ]
  Stage A (Waiting for B) ◄────────────────────────┐
             │                                     │
             ▼                                     │
  Stage B (Waiting for A) ─────────────────────────┘
  WITHOUT UPFRONT VALIDATION: Worker waits indefinitely, locking BullMQ queue slot!

 [ CANDIDATE FIX: UPFRONT DFS / KAHN'S CYCLE DETECTION (dag.js) ]
  Parse Graph ──► Compute In-Degree ──► Detect Back-Edge (recStack.has(node))
                         │
                         ▼ Cycle Found
  Reject Pipeline in < 1ms with HTTP 400 & descriptive cycle error!
  Zero containers provisioned. Zero queue worker slots wasted.
```

### Bug #3: Git Auto-Revert Infinite Webhook Feedback Loop
```
 [ NAIVE AUTO-REVERT FLOW ]
  1. Build fails on main branch ──► Auto-revert bot runs `git revert`
  2. Bot pushes revert commit to GitHub ──► GitHub fires push webhook
  3. Webhook triggers new build ──► If new build fails ──► Reverts the revert!
  RESULT: Infinite recursion storm flooding repository history!

 [ CANDIDATE FIX: COMMIT-AUTHOR CIRCUIT BREAKER (webhooksController.js) ]
  Incoming Webhook ──► Check headCommit.author.name === 'Magnus CI'
                             │
            ┌────────────────┴────────────────┐
          YES (Bot Commit)                  NO (Human Developer)
            │                                 │
            ▼                                 ▼
   Drop webhook immediately!          Enqueue to BullMQ
   Log: "Skipping CI loop"            Execute pipeline
```
